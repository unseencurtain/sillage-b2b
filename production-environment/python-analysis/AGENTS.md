# python-analysis (wholesale-perfumes)

Photo helpers for this shop. Retail BeautyFort + BTS matchers live in
[unseencurtain/Sillage](https://github.com/unseencurtain/Sillage).

The `beautyfort-enriched/` tree is **not** in this repo. Do not add it back.

Useful leftovers:

- `ean-image-scrape/` — fill missing photos by EAN (generic, not BeautyFort-specific)
- `photo-pack/` — snapshot of a historical media inventory (includes retail CDN counts; not a connector)

Vendor sync and image rules live in `sillage-core`.
